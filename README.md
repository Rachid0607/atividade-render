# Grandes SP

Painel interativo sobre cursos dos grandes times de Sao Paulo.

## Executar localmente

```bash
npm install
npm start
```

Abra `http://localhost:3000` no navegador.

## Publicar no Render

1. Envie este repositorio para o GitHub.
2. No Render, crie um novo **Web Service** conectado ao repositorio.
3. Use `npm install` como Build Command e `npm start` como Start Command.
4. O Render define a variavel `PORT` automaticamente.
